# 💰 Expense Tracker using Flask

A simple Expense Tracker web application developed during my **first year of university** as a beginner project to learn **Flask**, **SQLite**, and basic **CRUD operations**.

This project was built to understand how a backend web application works by connecting a Flask server with a SQLite database and rendering data using HTML templates.

> **Note:** This is an early learning project and was created as part of my first-year programming journey.

---

## 📌 Features

* ➕ Add a new expense
* 📋 View all expenses
* ✏️ Update existing expenses
* 🗑️ Delete expenses
* 🔍 Search expenses by name
* 💾 Store data using SQLite database

---

## 🛠️ Tech Stack

* Python
* Flask
* SQLite
* HTML
* CSS

## 🚀 Getting Started

### 1. Clone the repository

```bash
git clone https://github.com/Rishikeshsanin/Flask-py.git
cd Flask-py
```

### 2. Install dependencies

```bash
pip install -r requirements.txt
```

### 3. Run the application

```bash
python app.py
```

### 4. Open your browser

```
http://127.0.0.1:5000
```
